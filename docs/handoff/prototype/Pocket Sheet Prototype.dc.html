Portraits

On hardware you copy a 48×48 BMP (24-bit or 8-bit) to the microSD. Here, pick any image: it's center-cropped to 48×48, saved as a BMP on the simulated card, then shown at 15-bit color.

Spell library file

The app ships with 41 starter spells. On hardware you add your own by editing spells.txt on a PC. Here you can edit the simulated file, then reboot to load it.

Simulated only

The SD card is browser storage. The lid switch, the boot delay, the dice randomness and the dimmed top screen behind dialogs (a brightness fade on hardware) are all stand-ins. Screens, layout, controls and save bytes match the native spec.
